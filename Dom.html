🎯 Demostración de Métodos para Añadir Botones

Compara diferentes formas de crear botones dinámicamente en JavaScript

📌 1. getElementById - Selecciona por ID

¿Qué hace? Selecciona UN elemento por su ID único. Es el método más rápido.

Ventajas: Muy rápido, fácil de usar, devuelve directamente el elemento.

const elemento = document.getElementById("miId"); elemento.style.background = "yellow";

📌 2. querySelector - Selecciona el PRIMER elemento

¿Qué hace? Selecciona el PRIMER elemento que coincida con un selector CSS.

Ventajas: Muy flexible, usa selectores CSS, fácil de leer.

// Busca el primer elemento con esa clase const elemento = document.querySelector(".mi-clase"); elemento.style.background = "lightblue";

📌 3. querySelectorAll - Selecciona TODOS los elementos

¿Qué hace? Selecciona TODOS los elementos que coincidan con un selector CSS.

Ventajas: Devuelve una lista de elementos, puedes recorrerlos todos.

// Busca TODOS los elementos con esa clase const elementos = document.querySelectorAll(".mi-clase"); elementos.forEach(el => { el.style.background = "lightgreen"; });

📌 4. getElementsByClassName - Selecciona por clase

¿Qué hace? Selecciona TODOS los elementos con una clase específica.

Ventajas: Colección "viva" que se actualiza automáticamente si el DOM cambia.

// Busca todos los elementos con esa clase const elementos = document.getElementsByClassName("mi-clase"); for (let i = 0; i < elementos.length; i++) { elementos[i].style.background = "orange"; }

📌 5. getElementsByTagName - Selecciona por etiqueta HTML

¿Qué hace? Selecciona TODOS los elementos de un tipo de etiqueta HTML.

Ventajas: Útil cuando quieres todos los botones, divs, etc.

// Busca TODOS los botones en un contenedor const caja = document.getElementById("mi-caja"); const botones = caja.getElementsByTagName("button"); for (let boton of botones) { boton.style.background = "pink"; }

📌 6. getElementsByName - Selecciona por atributo name

¿Qué hace? Selecciona elementos por su atributo "name" (común en formularios).

Ventajas: Útil para trabajar con inputs, radios y checkboxes.

// Busca elementos con el atributo name="usuario" const inputs = document.getElementsByName("usuario"); inputs[0].value = "¡Hola!";

1. appendChild() ✓ Recomendado

¿Qué hace? Crea elementos nuevos desde cero y los añade al DOM.

Ventajas: Los eventos se mantienen, es más rápido y eficiente.

const CAJA = document.querySelector(".caja"); for (let k = 0; k < 10; k++) { const BOTON = document.createElement("button"); BOTON.textContent = `Boton ${k+1}`; BOTON.classList.add("bt" + k); CAJA.appendChild(BOTON); BOTON.addEventListener("click", saludar); } function saludar() { alert("Hola"); }

2. innerHTML += ✗ No recomendado

¿Qué hace? Reemplaza todo el contenido HTML existente.

Problemas: Elimina eventos anteriores, recrea todo el DOM, es lento.

const CAJA = document.querySelector(".caja"); for (let k = 0; k < 10; k++) { CAJA.innerHTML += `<button>Cancelar</button>`; document.querySelectorAll("button")[k].addEventListener("click", saludar); } function saludar() { alert("Hola"); }

3. insertAdjacentHTML() ✓ Buena alternativa

¿Qué hace? Inserta HTML nuevo sin tocar el contenido existente.

Ventajas: Más eficiente que innerHTML +=, no recrea todo.

const CAJA = document.querySelector(".caja"); for (let k = 0; k < 10; k++) { CAJA.insertAdjacentHTML("afterend", `<button class="bt${k}">Boton ${k+1}</button>`); document.querySelector(".bt" + k).addEventListener("click", saludar); } function saludar() { alert("Hola"); }
